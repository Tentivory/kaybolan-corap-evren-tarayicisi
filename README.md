## 📜 Bu Nedir?

Bu proje, insanlık tarihinin en büyük sorunlarından birini çözmek için geliştirilmiştir:  
**Kaybolan çoraplar.**

Yıllarca süren araştırma, 17 adet boş kahve fincanı ve bir kediyle yapılan müzakereler sonucunda,  
çamaşır makinelerinin aslında düşük güçte çalışan kara delikler olduğu teorisi doğrulanmıştır.  
Bu yazılım, kuantum dolanıklık prensibini kullanarak kaybolan çoraplarınızın  
evrendeki olası konumlarını **bilimsel olarak** (yani rastgele) tespit eder.

---

## 🚀 Kurulum

```bash
git clone https://github.com/Tentivory/kaybolan-corap-evren-tarayicisi.git
cd kaybolan-corap-evren-tarayicisi
python3 corap_tarayici.py
```

Başka bir şeye gerek yok. Gerçekten.  
Bağımlılık yok. Sadece umut ve bir miktar sabır.

---

## 🧪 Nasıl Çalışır?

1. Program başlar.
2. 7 aşamalı sahte tarama yapar (çok inandırıcı).
3. Rastgele bir konum seçer.
4. Size "güven skoru" gösterir (hiç güvenmeyin).
5. Siz de "vay be bilim" dersiniz.

Kullanılan ana teori: **Schrödinger'in Çorabı**  
(Çorap hem var hem yoktur, siz bakana kadar.)
